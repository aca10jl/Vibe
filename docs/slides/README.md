# 方案演示 PPT

面向团队的图解提案，用于说服将 **AI 伴读助手** 集成进现有「一键一生」框架。

- **`一键一生-AI助手-方案.pptx`** — 可直接放映/编辑的演示文稿（16:9，14 页，深色专业主题）。用 PowerPoint / WPS / Keynote / Google Slides 打开。
- **`make_pptx.py`** — 生成脚本，内容如需调整改这里后重跑即可：
  ```bash
  pip install python-pptx
  python3 make_pptx.py        # 重新生成 .pptx
  ```
